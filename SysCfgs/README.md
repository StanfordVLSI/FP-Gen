#### How to configure FP-Gen
Note there are several ways to use the configs and/or otherwise set specific Genesis parameters, e.g.
```
  make gen GENESIS_CFG_SCRIPT=SysCfgs/cma.cfg                 # Config file
  make gen GENESIS_PARAMS="top_FPGen.FPGen.Architecture=CMA"  # Cmd line option 1
  make gen GEN="-parameter top_FPGen.FPGen.Architecture=CMA"  # Cmd line option 2
```

#### Pre-built config files
```
  bf-cma.cfg    # Pipelined   16-bit bfloat CMA w/Sklansky adder
  bf-cma00.cfg  # Unpipelined 16-bit bfloat CMA
  bf-fma.cfg    # Pipelined   16-bit bfloat FMA
  bf-fma00.cfg  # Unpipelined 16-bit bfloat FMA
  cma.cfg       # Default CMA with Wallace trees (might be same as dp-cma.cfg?)
  dp-cma.cfg    # 64-bit DP CMA w/ denorm, forwarding, Wallace trees, Booth 3
  dp-fma.cfg    # 64-bit DP FMA w/ denorm, forwarding, array trees,   Booth 3, pipedepth 2
  sp-cma.cfg    # 32-bit SP CMA w/ denorm, forwarding, Wallace trees, Booth 3, pipedepth 3
  sp-fma.cfg    # 32-bit SP FMA w/ denorm, forwarding, ZM trees(?),   Booth 3, pipedepth 2
```

#### Default configuration
The default configuration, if no configuration file is specified, is a
double-precision 7-cycle FMA (fused mul-add) unit with 3-cycle pipelined
Booth-2 multiplier and Wallace summation trees. The major parameters are
listed in [default.txt](default.txt) ).

If you run "`make gen`" from the top level, it uses config [bf-cma.cfg](bf-cma.cfg).
If you want the default configuration, you would specify something like options 1 or 2 below.
```
  make gen                                       # Uses bf-cma instead of FP-Gen defaults
  make gen GENESIS_CFG_SCRIPT=SysCfgs/bf-cma.cfg # Same as "make gen"

  make gen GENESIS_CFG_SCRIPT=DEFAULT    # Option 1 for requesting default config
  make gen GENESIS_CFG_SCRIPT=/dev/null  # Option 2 for requesting default config
```

#### What else is here - default.txt
The "`default.txt`" file summarizes top-level default system parameters, it was generated by doing
```
      make clean gen GENESIS_CFG_SCRIPT=/dev/null  # Produces parm file FPGen.xml
      scripts/summarize_gen_params.py FPGen.xml    # Summarizes parm file
```
You can turn "`default.txt`" into a "`*.cfg`" style config file by doing something like this:
```
    cat default.txt | awk '/^PARM top.*=/ {
        parm = $2
        if ($4 ~ /^[0-9][0-9]*/)  val = $4; else val = "SSSQQQ" $4 "SSSQQQ"
        printf("configure( SSSQQQ%sSSSQQQ , %s );\n", parm, val)
    }'  | sed "s/SSSQQQ/'/g" | tee tmp.cfg
```
